# Employee Skill Matrix System
Enterprise employee skill tracking platform built using:- FastAPI- SQLAlchemy- Python- SQLite
## Features- Employee management- Skill tracking- Skill gap analysis- Learning recommendations- REST APIs
## Setup
### Install dependencies
pip install -r requirements.txt
### Run application
uvicorn app.main:app --reload
